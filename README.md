# BookMyTrip Responsive Website

A responsive travel landing page based on the supplied reference design. Prices are sample amounts in Indian Rupees (INR).

## Files
- `index.html`: page structure
- `style.css`: desktop, tablet and mobile layout
- `script.js`: mobile menu and demo enquiry form

## Run
Open `index.html` in your browser. Images require an internet connection.

## GitHub Pages
1. Create a public GitHub repository (e.g. `bookmytrip`).
2. Upload `index.html`, `style.css`, `script.js` to the repository root.
3. Go to Settings > Pages > Build and deployment, select Deploy from a branch.
4. Choose `main` and `/ (root)`, then Save.
5. Wait for GitHub to publish your website. The URL typically follows `https://YOUR-USERNAME.github.io/bookmytrip/`.

## Important
This is a frontend demonstration. It does not process payments or confirm reservations. The enquiry form saves entries to browser localStorage only; it does not send them to an administrator. Replace sample prices, imagery and placeholder policies before using as a real service.
